# Deck Slide Catalog

## Required Slide Types Per Deck

### 1. Title Slide
- Eyebrow: "CASH FLOW MACHINE / SESSION 0X"
- Massive headline (--hero size, weight 800)
- Subtitle in white-mid
- "Matt Gray / Founder OS" at bottom
- Green dot pulsing

### 2. Previous Session Recap (decks 2-6 only)
- Eyebrow: "LAST SESSION"
- 3-4 cards summarizing key takeaways from previous session
- Clean, visual, not text-heavy

### 3. The Promise
- Eyebrow: "AFTER THIS SESSION"
- 3 outcome cards in a row
- Specific, measurable outcomes

### 4. Billboard Statement Slides (2-3 per deck)
- `.billboard-slide` + `.billboard-text`
- ONE powerful sentence that fills the screen
- Lime squiggly underline on the hardest-hitting word
- Must be screenshot-worthy, quotable, poster-like
- Sprinkle at natural pause points (after framework, mid-deck, before close)

### 5. Framework Overview
- Visual diagram (2x2 grid, staircase, funnel, flow)
- Lime numbers on each item
- Never just bullet points -- always visual cards or diagrams

### 6. Framework Deep-Dives (1 slide per concept)
- Eyebrow with lime number: "01 / LEAK"
- Subhead title
- Insight card with key quote
- Animated severity bars or visual indicators
- 1-2 sentences max body text

### 7. Visual Diagrams (7+ per deck)
- SVG/CSS diagrams that animate on scroll
- Types: funnels, gauges, staircases, bar charts, before/after splits, timelines, flow diagrams
- Animated: bars fill, gauges sweep, counters increment, elements scale in
- Clean, geometric, data-driven -- not clipart

### 8. Live Exercise Block (4 slides)
- Step 01 through Step 04
- Lime number on each step
- Specific instruction + what a good answer looks like
- Final step: "Share in the chat" for group accountability
- NOT overwhelming -- one clear action per step

### 9. Case Studies (2 slides)
- Eyebrow: "CASE STUDY"
- Founder story with before/after numbers
- Diagnosis + Fix format in cards
- Different angles: one external founder, one Matt's story or internal example

### 10. Homework Slide (1 item only)
- Eyebrow: "BEFORE SESSION [N+1]"
- Subhead: "Your Homework"
- Session timeline (6 dots, current session pulsing lime, previous solid lime, future gray)
- ONE homework item in a clean card -- NO number
- Short motivating line underneath
- Timeline animates: line draws left-to-right, dots pop in, active pulses

### 11. Velocity Seed/Pitch Slide
- Sessions 1-3: Billboard style, subconscious seeding (no product name, no CTA)
- Sessions 4-5: Warm pitch with booking CTA
- Session 6: Full 3-4 slide conversion sequence (pattern interrupt, offer, math, social proof, CTA)

### 12. Next Session Preview
- Eyebrow: "NEXT SESSION"
- Headline title of next session
- 3 preview bullets
- Date/time placeholder

### 13. Closing Slide
- "Let's build." in display text
- Pulsing green dot
- "The Cash Flow Machine / Session 0X / Matt Gray"

## Text Density Rules
- Maximum 1-2 sentences of body text per slide
- Replace paragraphs with visual elements
- If you need to explain something complex, use more slides not more text
- Each slide = ONE idea
