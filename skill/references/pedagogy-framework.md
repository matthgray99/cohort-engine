# Pedagogy Framework

## Core Principle
Maximum learning with minimum cognitive overload. Every slide teaches ONE concept. Every exercise has ONE clear output.

## Cognitive Engagement Strategies (Applied to Decks)

### 1. Advance Organizer
- "After this session, you will..." slide at the start
- Sets expectations, reduces anxiety, creates commitment

### 2. Previous Session Recap (Decks 2-6)
- "Last Session We Covered..." with 3-4 visual cards
- Spaced repetition: revisiting previous material strengthens retention
- Creates continuity and narrative arc

### 3. Chunking
- ONE concept per slide
- Break multi-step frameworks into individual slides (e.g., 5 Revenue Stages = 5 slides)
- Never combine two frameworks on one slide

### 4. Dual Coding
- Every framework has BOTH visual diagram AND text
- Visual: SVG diagrams, animated bars, gauges, funnels, staircases
- Text: short label + 1 sentence explanation
- People remember 65% of visual information vs 10% of text-only

### 5. Progressive Disclosure
- Build complexity gradually across sessions
- Session 1 = diagnosis. Session 6 = execution plan.
- Each session builds on the previous one's output

### 6. Retrieval Practice
- Live exercises force founders to apply concepts to THEIR business
- "What is YOUR margin?" not "What is a margin?"
- Share-in-chat moments create social retrieval

### 7. Concrete Examples
- 2 case studies per deck with real before/after numbers
- Abstract frameworks become real when attached to a founder's story
- One external example + one Matt's own story

### 8. Self-Explanation
- Worksheet tie-ins force founders to explain concepts in their own context
- "Name YOUR Cashflow Constraint" not "Define a Cashflow Constraint"

### 9. Emotional Anchoring
- Billboard slides create emotional pause points
- Screenshot-worthy moments that founders associate with the learning
- "Revenue is not the goal. Predictable, high-margin cash flow is the goal."

### 10. Implementation Intent
- Homework is ONE item (not overwhelming)
- Specific: "Complete the worksheet" not "Review the material"
- Motivating: connects homework to next session readiness

## Live Exercise Design Rules
- 4 steps per exercise (4-5 slides)
- Step-by-step, not overwhelming
- Each step has: clear instruction + what a good answer looks like
- Final step = share/accountability moment
- Total exercise time: 30 minutes during live session

## Text Density Rules
- Max 1-2 sentences body text per slide
- If you need more, use more slides
- Visual > text for every framework
- Billboard slides = 1 sentence only
- Card content = headline + 1 line max
